# Relatórios

Os arquivos Markdown gerados por `scripts/analisar_metricas.py` ficam aqui. O nome automático usa data e hora para preservar o histórico:

`relatorio-AAAA-MM-DD-HHMMSS.md`

Um relatório registra o estado dos CSVs naquele momento; ele não substitui os dados de origem. Para uma revisão editorial consistente:

1. gere um relatório depois de completar cada janela de coleta;
2. compare o vídeo à mediana da mesma janela, não a vídeos com idades diferentes;
3. avalie embalagem com impressões e CTR em conjunto;
4. avalie entrega com retenção aos 30 segundos e percentual médio assistido;
5. registre a decisão no arquivo `09_POST_MORTEM.md` do episódio.

Relatórios com poucos vídeos são úteis para conferir o processo, mas ainda não formam uma referência robusta. Preserve os relatórios antigos para observar se as decisões tomadas produziram melhora nas publicações seguintes.
