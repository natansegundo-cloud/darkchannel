# Inbox de capturas

Coloque aqui os prints originais do YouTube Studio antes de transcrever os dados para os CSVs. Esta pasta funciona como evidência visual e fila de processamento; ela não é lida automaticamente pelo analisador.

## Nome dos arquivos

Use:

`AAAA-MM-DD_VIDEO-ID_JANELA_TELA.extensao`

Exemplos válidos:

- `2026-10-02_CO-001_24h_reach.png`
- `2026-10-04_CO-001_72h_engagement.png`
- `2026-10-29_CO-001_28d_audience.jpg`

Para cada janela, capture quando disponível:

- visão geral com visualizações, horas e inscritos;
- alcance com impressões, CTR e fontes de tráfego;
- engajamento com duração média, percentual médio e curva de retenção;
- audiência com novos e recorrentes;
- receita após a monetização.

Antes de salvar ou compartilhar uma captura, oculte e-mail, dados de pagamento, identificadores pessoais e qualquer informação de outros canais. Não recorte o período selecionado nem o título do vídeo: ambos são necessários para auditar a transcrição.

Depois que os números forem lançados em `analytics/dados/snapshots.csv`, mantenha a captura com o mesmo nome. Se uma imagem estiver ilegível, acrescente `__REFAZER` ao nome e não estime valores.
